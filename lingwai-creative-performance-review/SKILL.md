# 零外素材投放复盘

## 目标

用真实数据判断钩子、卖点、画面和转化信息是否有效，避免凭主观偏好反复改文案。

## 输入

素材编号、上线日期、钩子类型、主卖点、镜头结构、价格口径、消耗、3秒留存、完播率、点击率、转化率、成交成本和GMV。指标口径必须来自同一平台和统计窗口。

## 输出

1. 按钩子、卖点、时长和镜头类型拆分表现。
2. 列出“保留放量、改写测试、暂停”的素材及原因。
3. 形成下一周测试假设，例如保留高点击钩子、替换低完播开头、复用高转化镜头。
4. 把已证实规则写入项目优化日志；未验证假设不得升级为默认规则。

## 边界

- 不混用不同平台、不同归因窗口或不同价格活动的数据。
- 样本量不足时只标记为“待验证”，不直接下结论。
- 数据复盘不替代合规审核；高表现素材仍需通过产品事实和价格复核。
