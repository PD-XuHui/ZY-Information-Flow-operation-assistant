# 零外素材入库与调用

## 目标

把“逐条打开视频找镜头”的工作，转为按镜头类型直接调用。先保证素材清晰、可找、可复用，再追求过细分类。

## 推荐目录

- `01_待整理`：刚导入、尚未看完的原片。
- `02_通用素材`：人物、场景、B-roll、字幕和价格卡模板。
- `03_产品素材/Pxxx_产品名`：产品资料、RAW、可剪辑素材、废片。
- `04_每周生产`：本周脚本、分镜、工程和交付。
- `05_成片库`：完成的视频。
- `06_授权与素材来源`：下载素材、授权与来源记录。

## 入库流程

1. 原片先进入 `01_RAW原始素材`，不改写母文件。
2. 快速预览后，把合格片段复制或导出至 `02_可剪辑素材`。
3. 用“产品_镜头类型_动作_角度_序号”命名，例如 `P001_上脸_调整鼻翼_近景_01.mp4`。
4. 废片保留在产品目录的“废片”，不混入可剪辑素材。
5. 每周剪辑优先调用已有可剪辑素材；只对镜头汇总中的高优先级缺口补拍。

## 边界

本 Skill 负责目录、命名和人工标签建议，不默认声称能自动识别视频内容。素材授权与下载来源必须单独留档。
