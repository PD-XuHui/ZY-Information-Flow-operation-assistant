# 零外周内容测试矩阵

## 目标

先设计本周测试方向，再写文案，避免批量素材只换词、不换钩子和卖点。

## 输入与输出

输入本周交付数量、内容类型、时长、已有素材、缺失镜头、产品事实和当天活动。输出每条的编号、钩子类型、唯一主卖点、转化信息、需要镜头和时长。

## 规则

- 每条只设一个主卖点。规格、成分、用法和价格只作必要辅助。
- 同一批同时测试痛点型、价格利益型、成分证据型、规格价值型和使用避坑型钩子。
- 相邻文案必须改变钩子、主卖点或镜头顺序至少一项。
- 先检查现有素材库。优先复用产品、使用、人物和B-roll通用镜头，不默认安排高难度独立场景。
- 带货内容必须有真实成交理由和动作指令；价格信息发布当天复核。
